# AI-Web-Scraper

## Overview
An AI-powered web scraper built using Python and Playwright to intelligently extract relevant information from websites. The project leverages AI-based parsing to identify key data even when webpage layouts change.

## Technologies Used
- Python
- Playwright
- AI / LLM

## Features
- Intelligent data extraction
- Robust scraping across layout changes
- Clean and structured output
